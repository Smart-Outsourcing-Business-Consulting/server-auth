This Odoo 18 compatibility addon lets an administrator choose a portal user in
an employee's **Related User** field. It changes only that picker in the
employee form.

The addon does not create employees, change user groups, or grant portal users
access to Human Resources data.

User and employee automation belongs to the downstream addon and is documented
in the pinned
[Microsoft Entra ID lifecycle guide](https://github.com/Smart-Outsourcing-Business-Consulting/miniorange_oauth_20/blob/57cbba126453e8ab6b4690da9678ec75571ecfb4/docs/entra_sso_administrator_guide.md).
